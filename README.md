## ✨ 核心功能

### 🔥 涨幅榜
实时 Top 30 涨幅股票，自动标记 **风险标签**（涨停/超高换手/巨量/题材炒作/不适合追高）

### 📂 板块榜
行业 + 概念双维度排名，领涨股追踪，涨跌家数一目了然

### 📈 放量异动
量比异常监控，即时捕捉资金异动信号

### 📋 每日复盘
自动生成市场总结：
- 市场广度统计（涨停/跌停/涨跌比）
- 最强板块 Top 5
- 高风险个股识别
- 市场情绪判断（强势/偏强/震荡/偏弱/弱势）

### 🎯 策略筛选
6 套选股策略，一键筛选：
| 策略 | 条件 |
|------|------|
| 低位放量 | 涨幅 2%-7% + 量比 > 1.5 |
| 板块龙头 | 涨幅 > 5% + 换手 > 5% |
| 高股息/低PE | PE < 15 + 上涨 |
| 回调企稳 | 涨幅 0.5%-3% + 量比 ~1 |
| 强势突破 | 涨幅 > 7% |
| 缩量后放量 | 量比 > 2 + 上涨 |

### ⭐ 自选股
搜索 + 本地收藏，10 秒自动刷新，量比/换手率监控

## 🔴 风险标签系统

| 标签 | 触发条件 | 级别 |
|------|---------|------|
| 涨停 | 涨幅 ≥ 9.5% | 🔴 danger |
| 大涨 | 涨幅 7%-9.5% | 🟡 warning |
| 超高换手 | 换手率 > 20% | 🔴 danger |
| 巨量 | 量比 > 3 | 🔴 danger |
| 题材炒作 | 涨幅≥5% + 换手>15% | 🟡 warning |
| 不适合追高 | 涨停 + 换手>25% | 🔴 danger |
| 只适合观察 | 大涨 + 量比>3 | 🔵 info |

## 🏗️ 技术架构

```
前端 (React + Vite)
  │
  ├── 10s 轮询 ──→ 后端 (Flask REST API)
  │                   │
  │              ┌────┴────┐
  │         东方财富 API   本地模拟
  │         (实时行情)     (自动降级)
```

- **前端**: React 18 + Vite + 深色主题 UI
- **后端**: Python Flask + 东方财富实时数据
- **部署**: Nginx 反代 + systemd 常驻

---

## 🚀 快速开始

### 本地开发

```bash
# 1. 启动后端
cd backend
pip install flask flask-cors requests
python3 server.py
# → http://localhost:5001

# 2. 启动前端
cd frontend
npm install
npx vite
# → http://localhost:3000
```

### VPS 部署

```bash
# 参考 backend/server.py + nginx 配置
# 前端构建: npm run build → dist/
# 后端: systemd 常驻 + nginx 反代到 80 端口
```
